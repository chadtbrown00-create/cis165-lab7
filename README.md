# Lab 7: BMI and Color Mixer

## Program 1: BMI Plan
- Inputs: Weight in pounds and height in inches.
- Variables: weight, height, and bmi.
- Validation: Check that weight and height are greater than zero.
- Calculation: Use the BMI formula: weight * 703.0 / (height * height).
- Output: Display BMI to two decimal places and its weight category.
- Tests: Underweight, optimal weight, overweight, and invalid measurements.

## Program 2: Color Mixer Plan
- Inputs: Two primary-color names.
- Variables: Two character arrays to store the colors.
- Validation: Check that both inputs are red, blue, or yellow.
- Comparisons: Use strcmp to compare the color names.
- Output: Display the resulting mixed color or an error message.
- Tests: All three mixtures, reversed input orders, matching colors, and invalid colors.
